# SysDB — Система управления базами данных

## Описание

**SysDB** — это учебная реляционная СУБД, реализованная на C++17. Проект демонстрирует основные принципы работы баз данных, включая хранение данных, индексацию, транзакции и выполнение SQL-подобных запросов.

## Возможности

- **Управление базами данных**: создание, удаление, переключение между БД
- **Управление таблицами**: создание и удаление таблиц с указанием типов колонок
- **Операции с данными**:
    - `INSERT` — добавление записей
    - `DELETE` — удаление записей с условием WHERE
    - `UPDATE` — обновление записей с условием WHERE
    - `SELECT` — выборка данных с поддержкой агрегатных функций
- **Индексы**: автоматическая индексация колонок с использованием **B+ деревьев**
- **WAL (Write-Ahead Logging)**: журнал предзаписи для восстановления после сбоев
- **Агрегатные функции**: `COUNT`, `SUM`, `AVG`
- **Интерактивный CLI**: командная строка для выполнения запросов
- **Пакетный режим**: выполнение SQL-скриптов из файлов

## Сборка

### Требования

- CMake ≥ 3.14
- Компилятор с поддержкой C++17 (GCC, Clang)
- pthread

### Инструкция

```bash
mkdir build
cd build
cmake ..
make
```

После сборки исполняемый файл `sysdb` будет доступен в директории `build/`.

## Использование

### Интерактивный режим

```bash
./sysdb
```

### Пакетный режим (выполнение скрипта)

```bash
./sysdb script.sql
```

## Примеры команд

### Базы данных

```sql
CREATE DATABASE mydb;
USE mydb;
DROP DATABASE mydb;
```

### Таблицы

```sql
CREATE TABLE users (
    id INT NOT NULL INDEX,
    name STRING NOT NULL,
    age INT,
    email STRING DEFAULT 'unknown@example.com'
);

DROP TABLE users;
```

### Вставка данных

```sql
INSERT INTO users (id, name, age, email) VALUES (1, 'Alice', 25, 'alice@example.com');
INSERT INTO users VALUES (2, 'Bob', 30, 'bob@example.com'), (3, 'Charlie', 35, 'charlie@example.com');
```

### Выборка данных

```sql
SELECT * FROM users;
SELECT name, age FROM users WHERE age > 25;
SELECT COUNT(*) FROM users;
SELECT SUM(age), AVG(age) FROM users WHERE age > 20;
```

### Обновление и удаление

```sql
UPDATE users SET age = 26 WHERE name = 'Alice';
DELETE FROM users WHERE id = 1;
```

## Поддерживаемые типы данных

- `INT` — целочисленный тип
- `STRING` — строковый тип

## Модификаторы колонок

- `NOT NULL` — запрет на пустые значения
- `INDEX` — создание индекса по колонке
- `DEFAULT <value>` — значение по умолчанию

## Операторы сравнения в WHERE

- `=`, `<>` — равно / не равно
- `<`, `>`, `<=`, `>=` — сравнение
- `BETWEEN` — диапазон значений
- `LIKE` — шаблонное совпадение

## Логические операторы

- `AND` — логическое И
- `OR` — логическое ИЛИ
